# MUTE.

MUTE.는 성수동의 밝고 여백 있는 공간에서 스페셜티 커피와 계절 디저트를 즐기는 퓨어 화이트 미니멀 카페 홈페이지입니다. 좋은 커피와 잠깐의 쉼을 전하는 브랜드 소개, 메뉴, 매장 안내를 한 페이지에 담았습니다.

## 주요 기능

- **퓨어 화이트 미니멀 UI** — 화이트 배경, 쿨그레이 섹션, 얇은 구분선과 넉넉한 여백을 사용한 반응형 디자인
- **메뉴 12종 필터링** — 커피, 논커피, 디저트 카테고리별 메뉴 보기
- **실시간 예상 금액 계산기** — 메뉴를 담을 때 수량과 예상 결제 금액을 계산하고 한 번에 비우기
- **인터랙션 효과** — IntersectionObserver 페이드업, 메뉴 이미지 호버 확대, 글래스모피즘 내비게이션과 주문 바
- **이미지 대체 처리** — Unsplash 이미지 로딩에 실패하면 미니멀한 대체 배경 표시

## 기술 스택

- HTML5
- CSS3 (반응형 스타일, 애니메이션)
- Vanilla JavaScript
- Git / GitHub
- Google Fonts: Plus Jakarta Sans, Instrument Serif (Pretendard 폰트 스택 포함)

## 실행 방법

별도의 빌드나 패키지 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

로컬 서버를 사용하려면 저장소 폴더에서 다음 명령을 실행한 뒤 `http://localhost:8000`을 여세요.

```bash
python -m http.server 8000
```

Google Fonts와 Unsplash 이미지는 네트워크 연결이 필요합니다. 이미지 요청에 실패하면 페이지 내 대체 배경이 표시됩니다.
